# Sleepless

A native Mac menu-bar utility for turning the system-wide sleepless setting on and off. It shows the actual system setting, including changes made outside the app. When enabled, the Mac can continue working with its lid closed. The user can optionally open the app at login.

Use the existing macOS menu, icons, authentication and login-item controls. The setting persists when the app quits; other processes can independently prevent sleep.
